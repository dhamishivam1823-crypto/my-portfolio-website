# Responsive Portfolio Website — Demonstration Project

This is a small front-end demonstration project prepared to accompany the internship presentation. It reflects topics listed in the internship report: landing pages, responsive layouts, navigation menus, contact forms, portfolio pages and website testing.

## Files
- `index.html` — semantic page structure and sections
- `style.css` — visual design, layout and responsive media query
- `script.js` — mobile navigation and client-side form validation

## Run
1. Extract the ZIP file.
2. Open `index.html` in Google Chrome or another modern browser.
3. Resize the browser to test desktop and mobile layouts.
4. Try submitting the contact form with empty fields, an invalid email, and valid sample details.
